Features

1. Dynamic Background — Background images automatically change using JavaScript.

2. Background Video Toggle — Option to enable or disable a looping background video on the Games page.

3. Modal Trailer Player — You can click on a game image to open a popup trailer using an embedded YouTube iframe.

4. Swipe Slider — Horizontal swiper/slider to showcase content interactively.

5. Responsive Design — Each page adapts to different screen sizes with CSS styling.


How to Run
Option 1 — Run Locally

1. Download or clone the repository.

2. Make sure all folders (styles, javascript, images, videos) remain in the same directory as the HTML files.

3. Open index.html in your web browser.

4. You can navigate between pages using the links in the navigation bar.

Option 2 — View Online

The website is also deployed online using:

- GitHub Pages

- Vercel

Simply visit the provided deployment link to view the live site.
